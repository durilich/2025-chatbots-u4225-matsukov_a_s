# Лабораторная работа 3. Деплой и обратная связь

## Описание деплоя

Способ запуска — Railway, бесплатный план. Бот уже ходит в Telegram сам, командой `python bot.py`, поэтому на сервере запускается тот же процесс. Компьютер после деплоя можно выключать.

В репозитории для этого лежат `lab2/Procfile` и `lab2/railway.toml`. Токен задаётся переменной `TELEGRAM_BOT_TOKEN` в панели Railway. Публичный адрес и webhook не используются.

URL сервиса и скриншот логов будут добавлены после первого успешного запуска.
