# Лабораторная 2. Задачи и привычки в SQLite

Тот же Telegram-бот, что в лабораторной 1, но задачи и привычки хранятся в базе `bot.db`. При первом запуске бот один раз читает `lab1/tasks.json`, если база ещё пустая, и не изменяет этот файл.

Зачем SQLite: по базе можно выбрать задачи за неделю, найти задачу по тексту и показать историю выполненных и отменённых. Раньше для этого пришлось бы каждый раз разбирать весь JSON.

## Запуск

Нужен Python 3.11 или новее и токен от [@BotFather](https://t.me/BotFather). Подойдёт тот же бот, что в первой лабораторной.

macOS и Linux:

```bash
cd lab2
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

Windows:

```bat
cd lab2
py -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env
```

В `.env` вставьте токен после `TELEGRAM_BOT_TOKEN=`. Файл `.env` и база `bot.db` в git не попадают.

```bash
python bot.py
```

Остановка: Ctrl+C. Напоминания приходят, пока процесс запущен. После нового запуска бот снова ставит будущие напоминания из базы.

Не запускайте одновременно бота из `lab1` и из `lab2`: у них один токен, Telegram принимает только одно подключение.

## Новые кнопки и команды

- «За неделю» или `/week` — задачи за последние 7 дней, включая сегодня. Учитываются и день выполнения, и дата создания.
- «Найти» или `/find отчёт` — поиск по тексту без учёта регистра.
- «История» или `/history` — выполненные и отменённые задачи, сначала новые.

Кнопки и команды первой лабораторной на месте: сегодня, все задачи, просрочено, новая задача, привычки, статистика, напоминания и приоритеты.
