# 2025-chatbots-u4225-matsukov_a_s

Репозиторий лабораторных работ по курсу [Vibe Coding: AI-боты для бизнеса](https://github.com/itmo-ict-faculty/vibe-coding-for-business), Университет ИТМО, факультет ИКТ.

- **Год:** 2025/2026
- **Группа:** U4225
- **Автор:** Мацуков Артём Сергеевич

Боты собираются через промпты к LLM в Cursor, а не ручным написанием кода. В каждой папке `labN` лежит отчёт `labN_report.md` и файлы проекта, если лабораторная связана с кодом.

## Структура

```text
lab1/   первый Telegram-бот
lab2/   вторая лабораторная
lab3/   третья лабораторная
```

## Запуск бота

Инструкция для конкретной работы лежит в `README.md` внутри её папки. Токен Telegram хранится только в локальном файле `.env` и в репозиторий не попадает: образец переменных — в `.env.example`.
