# Лабораторная 1. Ассистент задач и привычек

Telegram-бот принимает задачи текстом, назначает их на день, напоминает о них и ведёт привычки. Данные чата лежат в `tasks.json` рядом с `bot.py`.

## Запуск

Нужен Python 3.11 или новее и токен от [@BotFather](https://t.me/BotFather). Для этой работы username бота: `itmoftmi_mas_bot`.

macOS и Linux:

```bash
cd lab1
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

Windows:

```bat
cd lab1
py -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env
```

Откройте `.env` и вставьте токен после `TELEGRAM_BOT_TOKEN=`. Файл `.env` в git не попадает.

```bash
python bot.py
```

Остановка: Ctrl+C. Напоминания приходят, только пока этот процесс запущен. После повторного запуска будущие напоминания читаются из `tasks.json` и ставятся снова.

## Кнопки

После `/start` внизу чата появляются кнопки: «Сегодня», «Все задачи», «Просрочено», «Новая задача», «Привычки», «Статистика».

«Новая задача» спрашивает текст, затем приоритет и день. Под списком задач у номера есть кнопки: выполнена, отменена, напоминание, день и приоритет. В привычках отдельные кнопки отмечают день и открывают статистику.

## Команды

- `/add [приоритет] текст [ДД.ММ]` — новая задача. Приоритет: высокий, средний, низкий.
- `/date номер ДД.ММ` — назначить день.
- `/today` — задачи на сегодня.
- `/day ДД.ММ` — задачи на выбранный день.
- `/list` — все активные задачи.
- `/priority номер уровень` — сменить приоритет.
- `/remind номер ЧЧ:ММ` или `/remind номер ДД.ММ ЧЧ:ММ` — напоминание.
- `/done номер` — выполнена.
- `/cancel номер` — отменена.
- `/delete номер` — удалить без следа в статистике.
- `/overdue` — просроченные.
- `/stats` — активные, выполненные, отменённые, просроченные и сводка привычек.
- `/habit название` — новая привычка.
- `/habits` — список привычек.
- `/check название` — отметить за сегодня.
- `/uncheck название` — снять сегодняшнюю отметку.
- `/habitstats` — серии и доля дней за 7 и 30 дней.

Дата `ДД.ММ` означает текущий год. Полный вид: `ДД.ММ.ГГГГ`. Время и «сегодня» считаются по Москве.
